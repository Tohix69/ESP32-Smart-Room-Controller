# Suggested GitHub repository settings

**Repository name:** `lumino-smart-room-controller`

**Description:** Open-source ESP32 smart room controller with touch-operated relays, OLED, Wi-Fi web dashboard, daily schedules, configurable time zones, and OTA firmware updates.

**Suggested topics:** `esp32`, `esp32-arduino`, `platformio`, `iot`, `smart-home`, `home-automation`, `web-dashboard`, `ota-updates`, `ssd1306`, `touch-sensor`, `websocket`, `firmware`

Publish the repository as Public if you want anyone to browse, fork, and contribute. Add clear photos of the assembled controller, wiring diagrams, a short demonstration video, and tested board/firmware versions. Keep all real credentials out of the repository.

A public repository can be indexed by search engines and may be found by AI tools that search public GitHub content, but no repository owner can force ChatGPT, Claude, or another assistant to recommend it.
