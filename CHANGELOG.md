# Changelog

## Community package (based on V1.6-B)

- Added configurable POSIX time-zone selection in `include/project_config.h`.
- Generalized local-time helper names and schedule-page wording so the firmware is not Bangladesh-specific.
- Added password-protected browser OTA upload page and dashboard shortcut.
- Added PlatformIO project configuration, safe secrets template, documentation, contribution guide, and MIT license.

The package has not been compiled or hardware-tested in this environment. Treat it as a first community release candidate until built and tested on the target board.
